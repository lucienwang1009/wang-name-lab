# 王姓女孩取名实验室网页设计

## 产品目标

把现有的古籍取名数据、生成算法、评分规则和出生后复排流程迁移为一个 TypeScript 网页应用，部署到 `lucienwang1009/wang-name-lab` 的 GitHub Pages。网站可以公开访问，但出生日期、时辰、城市、家庭投票和私人备注只保存在访问者自己的浏览器中，不写入仓库，也不发送到服务器。

## 技术方案

采用 React、Vite 和 TypeScript 构建纯静态单页应用。GitHub Pages 只负责托管编译后的 HTML、CSS 和 JavaScript；候选生成、筛选、比较和评分全部在浏览器中完成。

项目按三层组织：

- `domain`：纯 TypeScript 类型、候选生成、典故提取、评分、排序和硬筛函数。
- `data`：古典用字、古籍片段、人工精审候选和否决规则。
- `ui`：React 页面、筛选器、对比栏、档案卡和本地出生信息表单。

现有 Excel 工作簿继续作为审计和离线导出格式，但不再充当规则源。网页端 TypeScript 数据与规则成为后续维护的主实现。

## 信息架构

应用采用单页分区导航，不依赖服务端路由：

1. `总览`：展示字库、原始组合、典故候选、人工精审和硬筛通过数量。
2. `寻名`：搜索 25,440 个原始组合，按首字类别、次字类别、女性感、家族呼应和状态筛选。
3. `典故`：浏览古籍原文、人物场景、A—D 级取字路径和来源链接。
4. `精选`：查看文化评分、风险、家族关联和当前排序。
5. `对比`：最多选择四个名字横向比较。
6. `出生后`：录入本地出生资料、命理适配分和依据，进行双轨复排。
7. `方法`：解释传统命理边界、典故等级和硬筛原则。

导航状态使用 URL hash 保存，因此刷新页面不会触发 GitHub Pages 子路径 404。

## 数据与隐私

公开进入代码仓库的数据：

- 古典用字字典；
- 古籍原文种子与公开来源链接；
- 人工评分、风险和否决依据；
- 取名方法与计算规则。

只保存在浏览器 `localStorage` 的数据：

- 实际出生日期和时间；
- 出生城市、经度和真太阳时口径；
- 家庭收藏、淘汰、投票和备注；
- 出生后命理适配分及采用流派。

应用提供“导出本地档案”和“清除本地资料”操作。存储解析失败时恢复安全默认值，并在界面提示，不让损坏数据阻断页面。

## 视觉方向

视觉采用“宋版书页 × 现代档案馆”：

- 暖白纸色为主背景，深墨绿为结构色，朱砂红用于风险，旧金用于分级。
- 标题使用宋体气质的中文衬线字族，正文使用清晰的中文黑体字族。
- 页面保留版心、界栏、批注和藏书签式细节，但不模拟古风游戏界面。
- 首屏以一条纵向“筛选漏斗尺”呈现从 25,440 个原始组合到精选候选的收束过程。
- 动效克制：页面载入时逐层展开，筛选结果使用短促淡入，不使用连续漂浮装饰。

桌面端强调并列比较，移动端切换为卡片和底部对比抽屉。所有交互满足键盘导航、可见焦点和减少动态效果偏好。
